# Tadriss v2

School management for private institutions in Morocco: web (Next.js) + mobile (Expo) on Supabase.

```bash
pnpm install
pnpm dev:setup   # requires Docker
pnpm dev:web
```

Everything else (architecture, rules, commands) is in [CLAUDE.md](CLAUDE.md). Decisions are in
[docs/decisions](docs/decisions).
