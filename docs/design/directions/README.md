# Direction gallery captures

Each capture is a static review frame of the corresponding dev-only route. The canvas names are
the requested viewport widths: `375` for mobile and `1280` for desktop.

- `a` — Quiet Precision
- `b` — Warm Editorial
- `c` — Contemporary Maghreb
- `d` — Cinematic Studio

Open the live specimens at `/design/directions/a`, `/design/directions/b`, `/design/directions/c`,
or `/design/directions/d` under the locale route while running the web app in development or
preview mode.
